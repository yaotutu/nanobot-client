- 顶部只有左侧会话、中央头像 + 状态胶囊、右侧聊天选项三个入口。

- 流式中胶囊从 `nanobot` 切换为 `Thinking`，输入区切换为停止按钮。
- 消息操作默认收起为 `...`，展开后显示复制、引用、分支、重试；再次点击可收起。
- 浅色、深色模式下头部、气泡、输入框和回到底部按钮均正常。
