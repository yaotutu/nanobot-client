# 消息页 UI 校准验收（2026-10-07）

> 此记录与截图为上一阶段的布局，包含已被移除的常驻模型栏。当前入口与最终验收请见[聊天选项集中化记录](../chat-options-2026-10-07/README.md)。

## 范围与参考

本轮只重构聊天页视觉层。参考本地 OpenMuse 仓库提交 `73a714963b57e5cd1747fd3fbc6833e09a36b81a` 的手机 UI：

- `apps/mobile/App.tsx`：顶栏、品牌层级与底部布局。
- `apps/mobile/src/chat.tsx`：气泡、输入框与最新消息入口。
- `apps/mobile/src/assistant-response.tsx`：Markdown 字号和段落间距。
- `assets/demos/2026-09-16/mobile.png`：视觉对照图。

没有接入 OpenMuse 的服务、业务状态或接口。nanobot REST、WebSocket、鉴权、模型目录、消息回放、控制器和 store 未修改；未新增依赖或历史兼容分支。
