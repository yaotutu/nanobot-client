# 设置页重构验证（2026-10-07）

## 参考与范围

参考本地 OpenMuse 提交 `73a7149` 的移动 UI：

- `apps/mobile/src/screens.tsx`：ConnectionsScreen 的分组列表、23px 圆角、61px 行高、29px 图标底板、轻分隔线和右侧箭头。
- `apps/mobile/src/ui.tsx` 与 `apps/mobile/App.tsx`：25px 页面标题、22px 内容边距与留白层级。
- OpenMuse 没有同等的独立主题／语言设置页。本轮是将这些真实视觉元素应用到 nanobot 的本地偏好，而非宣称逐屏复制它的设置功能。

删除旧的主题按钮和全部语言平铺布局，改为：

1. 首页的偏好分组只显示主题／语言当前值；账户分组独立显示退出。
2. 点击主题或语言进入选择页，右侧勾选标识当前值，立即沿用父层持久化，不增加保存按钮或另一份偏好状态。
3. 左上角与系统返回先返回首页；首页系统返回关闭设置。右上角关闭在任意页面关闭设置。
4. 关闭时卸载内部选择页状态，再次打开回到首页，不重建聊天模块。

没有新增依赖，没有修改网关接口、偏好存储协议或聊天选项。仅保留 light／dark，不额外引入跟随系统或服务端管理功能。新增六项说明／分组／返回文案同步全部十种语言。

## Android 模拟器实测

使用现有 `emulator-5554`、Metro 8081 与开发客户端，无需重复配置 Java／Android 环境。

- 从会话面板底部设置入口进入新首页。
- 检查浅色／深色、中文／英文首页及选择页，无文字越界或内容遮挡。
- 主题选择立即更新配色、勾选和首页摘要。
- 选择简体中文后标题与说明立即切换，返回首页显示新语言。
- 详情页 Android 返回回到首页；首页 Android 返回回到聊天。
- 从语言详情关闭后重新打开，回到首页，偏好仍然保留。
- 强制停止应用后冷启动，重新进入设置，中文与深色偏好仍然保留。
- 测试结束恢复测试前的英文／浅色偏好并回到聊天；没有发送消息或修改服务端会话。

退出的真实认证操作未在设备上执行，以免清除现有登录；回调顺序由 Native 测试验证。未实测 iOS、Web、平板或 TalkBack，不将这些场景计为通过。之前记录的长历史消息加载 ANR 不在本次设置 UI 修改范围内。
