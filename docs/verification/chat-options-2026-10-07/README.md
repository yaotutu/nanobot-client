# 聊天选项集中化验收（2026-10-07）

## 最终布局

本记录是消息页当前布局；[上一阶段的视觉校准记录](../chat-ui-2026-10-07/README.md)保留作过程对照，不代表当前配置入口。

- 主输入区只保留聊天输入、附件、发送／停止及已有建议与上下文；不常驻模型、工作区、权限控件。
- 会话页右上角的滑杆图标打开「聊天选项」底部弹窗，集中展示模型、工作区、权限。侧栏不再提供重复入口，新建会话继续保留在侧栏。
- 模型列表和工作区路径表单在同一个原生 Modal 内展开，不嵌套选择弹窗。
- 打开／关闭选项不重挂输入区、不清空聊天草稿。
- 新会话可按服务端能力选择工作区；已有会话或服务端禁止修改时只读。默认／完全访问继续遵守服务端能力和运行状态限制。
- 仅参考 OpenMuse UI，沿用 nanobot 控制器、模型目录、工作区状态和接口；删除旧配置栏及独立选择弹窗，不保留兼容分支。未新增依赖。
